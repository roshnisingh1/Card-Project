# Card-Project
📍 India Heritage Cards — Frontend UI Project  A clean and visually appealing card layout showcasing famous Indian heritage locations. This project focuses on component-based UI design, sharp spacing, and a modern aesthetic using pure HTML &amp; CSS.

#What This Project Delivers
	•	Responsive card layout
	•	Smooth, minimal UI with soft background
	•	High-quality images displayed in a neat grid
	•	Location + title info section styled like real travel apps
	•	Beginner-friendly but production-quality structure

# Why I Built This

To strengthen my frontend fundamentals — especially layout building, styling consistency, and creating reusable components without depending on tutorials.

🛠️ Tech Used
	•	HTML5
	•	CSS3
